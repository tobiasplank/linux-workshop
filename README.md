# Linux-Workshop

Dieses Repository enthält deutschsprachige Lernmaterialien für einen
praxisorientierten Linux-Workshop. Die Übungen führen vom sicheren Arbeiten im
Ubuntu-Terminal über Dateien, Benutzer und Berechtigungen bis zur
Systemadministration.

## Materialien

Zu jeder Lektion gibt es eine Markdown-Datei und eine PDF-Version. Die PDFs
eignen sich zum Lesen oder Ausdrucken; die Markdown-Dateien enthalten dieselben
Übungen und können direkt im Repository geöffnet werden.

## Arbeiten mit den Übungen

Die Übungen sind für eine Ubuntu-Umgebung ausgelegt. Lies jeweils die
Aufgabenstellung und Hinweise, bevor du Befehle ausführst. Einige Labs setzen
eine vorbereitete Übungsumgebung voraus. Änderungen am System oder die
Verwendung von `sudo` sind nur dann vorgesehen, wenn eine Aufgabe dies
ausdrücklich verlangt.
